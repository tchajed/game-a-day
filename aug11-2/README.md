# AI-generated museum

Create a 3D AI-generated museum. Use PlayCanvas for the 3D part. I want the museum to contain a gallery of oil on canvas paintings, created with GPT images. Create three rooms: portraits of animals (in a world where the animals are sentient and the nobility are getting portraits of themselves), ordinary objects in unusual settings, and large format landscapes from alien worlds with a wide range of nature/technology in them. Also have an explanation describing each gallery like you'd expect from a curator.
