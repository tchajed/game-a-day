# Game idea: parking simulator

A top-down 2D parking simulator. Multiple levels, but the most basic is parallel parking.

One goal is to explore different control schemes: tank controls, awkward controls that simulate driving (e.g., foot pedal, turn the wheel, switch to reverse). I also want a programming version where you write an algorithm.

I'm thinking a simple, clean style, but with more fidelity on the cars than anything else.
