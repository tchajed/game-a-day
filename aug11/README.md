# Coffee supply chain

I'm envisioning a game where you play through the whole coffee supply chain: barista, coffee shop owner, roaster, and processing / harvesting.

The way I'm currently envisoning this is you go through it from the customer-facing end (barista), play for a bit at one level, then move higher in the supply chain. At each stage you have to do some low-level mechanics, but then these get automated. I don't have a really coherent vision, but the core moment is about realizing that you need to go up the supply chain: so for example one idea was that you get better as a barista, but then you find the coffee itself is bad and have to source it better; and you perfect roasting but then have to go back to the processing.

There's a visual style I want to try here: first, I want each of these stages to be run by cute animals, and a distinct one for each stage (mice, badgers, rabbits, cats, ravens; if these were thematic that would be great but we should also prioritize good visuals). Second, I was thinking of having a geometric style with mostly rounded rectangles and circles, bright colors, and a few different layers stacked on each other.

Some key things I want in this prototype: you should have to do a mini game (similar to WarioWare but you repeat until you succeed) to make an espresso, including measuring, grinding, WDT, tamping, and starting and stopping the epsresso. No steaming milk in this prototype. There should be a completely separate "supplier selection" mini game where you interview and negotiate with suppliers. Let's focus on these two to keep this manageable to one day.

I really want to have the coffee shop from the customer view (the bar, the back of the espresso machine/grinder, the barista) for the visual of it, even if from there you transition to other scenes (the barista view, the negotiation chats). The start of the game should be that view.

I'd like realism of the machines and process throughout, true to third wave speciality coffee, even if it's cute and digital art.
