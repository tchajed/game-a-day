# Psychopomps

The idea of this game is to play as a (new) psychopomp. I'm basically aiming for a certain mood, one where the main character is a bit staid, over-qualified for the job, but surrounded by bubbly characters, and all contrasted with the whole theme of helping the newly deceased go to the afterlife. It's a bit inspired by Grim Fandango.

The core idea that I want for the prototype is that the game starts with an onboarding for psychopomps - the idea being they were hired into the job. Our main character has never had this job but is highly trained (whatever that means), and is centuries older than the others being onboarded at the same time - the rest are L2 and they're L6, and yes we'll use Google levels for this.

The actual gameplay I was imagining is an RPG with hack-and-slash combat. The demo should just be the onboarding, which will include some in-world and in-game combat tutorial. The onboarding part will be an RPG in the style of maybe Final Fantasy 4, where you're walking around and doing onboarding tasks and talking to people. The game interface is side scrolling with a dialogue box at the bottom, like Pokemon.

I have a vision for how this the main character looks: they're all black, a tall figure with a pointed head. I was imagining they have few features and what they have is a geometric face. Some animation (perhaps just a handful of poses) is needed. Other characters will be a mix of animals (esp dogs, cats, anything else traditionally a psychopomp) and other humanoid creatures.

The game should have parallax side scrolling and a few different panes layered on each other. Everything is digital art. @art.jpeg provides some loose inspiration for the art style; maybe it could be described as comic book. I'll need some iteration to figure out what I want.
